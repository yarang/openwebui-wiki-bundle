이 안내를 읽었으면 지금 바로 Bash 도구로 아래 명령을 실행해 파일을 만든다. '이해했습니다' 같은 글 답으로 끝내지 않고, Skill 을 다시 부르지 않는다.
엑셀(.xlsx) 작업은 아래 명령만 쓴다. python 코드를 직접 만들지 않는다.
명령은 매번 전체 경로 ~/.claude/skills/xlsx/scripts/xlsx 로 쓴다. X= 정의나 $X 는 쓰지 않는다.
작업 파일(md)과 결과 파일은 현재 작업 폴더에 ./이름 으로 만든다. skill 의 Base directory 는 명령이 있는 곳일 뿐이며 거기에는 아무것도 쓰지 않는다. Markdown 저장에 Write 도구를 쓰지 말고 Bash heredoc 을 쓴다.
새로 쓰기: 시트마다 ## 시트이름 줄 다음에 Markdown 표를 쓴다. 표의 첫 행이 머리 행이다. 파일 이름은 사용자가 말한 파일 이름을 그대로 쓴다(아래 예시 이름은 예시일 뿐이다). 끝을 알리는 MD 는 혼자 한 줄에 쓰고, 변환 명령은 그 다음 줄에 쓴다(MD && 처럼 붙이지 않는다). Bash 한 번에 저장과 변환을 함께 한다.

```bash
cat > ./재고현황.md <<'MD'
## 재고
| 품목 | 수량 |
| --- | --- |
| 볼펜 | 120 |
| 공책 | 80 |
| 합계 | =SUM(B2:B3) |
MD
~/.claude/skills/xlsx/scripts/xlsx from-md ./재고현황.md
```

from-md 에는 md 경로 하나만 쓴다. 결과는 같은 이름의 .xlsx 파일로 생긴다(./재고현황.md → ./재고현황.xlsx).
숫자(1,000 · 3.5 · 12%)는 숫자 칸이 되고, = 로 시작하면 수식 칸이 된다. 0 으로 시작하는 번호(010-1234-5678, 007)와 날짜는 글자 그대로 남는다.
수식의 칸 주소는 머리 행이 1행, 첫 열이 A 열이다. 표 밖의 글 줄은 엑셀에 들어가지 않는다.
합계·평균은 계산한 숫자 대신 =SUM(B2:B4) 같은 수식으로 쓴다. 수식에는 ... 을 쓰지 말고 실제 칸 주소를 쓴다. 시트 이름과 머리 행은 사용자가 말한 그대로 쓰고, 단위는 머리 행에 쓴다(금액(천원)).
XLOOKUP·FILTER·SORT·UNIQUE·TEXTJOIN 은 옛 엑셀에서 안 열리므로 SUMIFS·INDEX/MATCH·IFERROR 를 쓴다.
사용자가 주지 않은 숫자·이름·날짜는 지어내지 않는다. 결과에 '경고 자리 표시' 줄이 있으면 무엇을 채워야 하는지 사용자에게 알린다. '경고 깨진 수식' 줄이 있으면 그 칸의 수식을 고쳐 새 이름으로 다시 만들고, 고친 칸을 사용자에게 알린다.
읽기: ~/.claude/skills/xlsx/scripts/xlsx read ./파일.xlsx
출력 파일이 이미 있으면 거부되므로 다른 이름을 쓴다.
결과 첫 줄이 OK 면 그 경로를 사용자에게 알린다. ERROR 면 그 사유를 사용자에게 알린다.
자세한 옵션: ~/.claude/skills/xlsx/scripts/xlsx --help
